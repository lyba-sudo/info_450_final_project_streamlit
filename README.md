# INFO 450 CPS Weekly Earnings Project

## Project Overview

This project analyzes U.S. weekly earnings using Current Population Survey
data from 2020 through 2025. The analysis focuses on education level, sex,
usual weekly hours, and earnings.

The repository includes an interactive Streamlit application that allows
users to filter the data and review updated summary statistics and
visualizations.

## Research Questions

1. How do weekly earnings differ by education level?
2. Is there a difference in weekly earnings between men and women?
3. How are usual weekly hours related to weekly earnings?

## Files

- `app.py` — Streamlit application
- `cps_project_data.csv` — CPS project dataset
- `requirements.txt` — Python packages required to run the app
